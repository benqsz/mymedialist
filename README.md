# mymedialist

Selfhosted media tracker for: Series, Movies, Anime, Manga, Books and games

## Features 
> **Work in Progress**

- [ ] Track media with status, rating, personal comment, favorite episode etc.
- [ ] Fetch Metadata from external providers 
- [ ] Create custom lists
- [ ] Share a single title, profile, or full lists publicly
- [ ] Time wasted tracker and charts
- [ ] Automatic import from popular tracking services
- [ ] New releases calendar with new media 
- [ ] Export to CSV
- [ ] Webhook/email notification
- [ ] News feed
